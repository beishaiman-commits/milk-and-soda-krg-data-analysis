## О проекте

**Вопрос:** в каком магазине корзина продуктов дешевле?

- Скрипт раз в день собирает цены с двух магазинов:
  - **Корзина** (korzinavdom.kz) — данные берутся из JSON API, который сайт сам использует для подгрузки товаров;
  - **Аян Маркет** (ayanmarket.kz) — разбор HTML-страниц через BeautifulSoup.
- Данные накапливаются в `tobaza.csv` (каждый запуск дописывает новые строки с датой).
- `analysis.py` чистит данные, сравнивает средние цены и «корзину» из типовых продуктов.
- `dashboard.py` показывает результаты в браузере.

Категории: молочные продукты и напитки.

## Использование

**1. Собрать цены** (запускать раз в день):

```bash
python price_parser.py
```

Результат дописывается в `tobaza.csv`. Между запросами к сайтам стоит пауза в 1 секунду.

**2. Проанализировать** (лучше, когда накопилось хотя бы 2 недели данных):

```bash
python analysis.py
```

Скрипт выведет таблицы и сохранит графики `chart_mean_prices.png` и `chart_basket.png`.

**3. Открыть интерфейс:**

```bash
streamlit run dashboard.py
```

### Как работает «корзина»

Названия товаров в магазинах не совпадают, поэтому они сопоставляются по ключевым словам. Правила лежат в словаре `BASKET`:

```python
"Кефир":  (["кефир"], []),
"Молоко": (["молок"], ["сгущ", "сух", "шоколад"]),  # (обязательные слова, исключения)
```

Для каждой позиции берётся самая дешёвая цена в каждом магазине за день, а в сравнение попадают только позиции, найденные в обоих магазинах.

## Ограничения

- В корзину берётся **самый дешёвый товар под правило**, а не одинаковый товар. Размер упаковки и бренд могут отличаться между магазинами.
- Данных за короткий период мало, чтобы судить о сезонности.
- Сравниваются только два магазина и только выбранные категории.
- Если сайт изменит вёрстку или API, парсер придётся поправить.
